Overview

Today you will build a model to answer this question: How are weekends and holidays associated with ridership, after accounting for the weather? Run the code below to select the columns we will use and fit five candidate models.

bikes <- bikes[, c("date", "season", "year", "month", "weekend", "holiday",
                   "temp_actual", "temp_feel", "humidity", "windspeed", "rides")]

bikes_A <- lm(rides ~ temp_actual + windspeed + weekend, data = bikes)
bikes_B <- lm(rides ~ temp_actual + windspeed + weekend + holiday, data = bikes)
bikes_C <- lm(rides ~ temp_actual + windspeed + weekend + holiday + humidity, data = bikes)
bikes_D <- lm(rides ~ temp_actual + windspeed + weekend + holiday + humidity + temp_feel, data = bikes)
bikes_E <- lm(rides ~ temp_feel + humidity + weekend + holiday, data = bikes)

Part 1: Look before you fit

temp_actual and temp_feel are almost perfectly correlated (\(r =\) 0.98). Including both would cause multicollinearity: they carry nearly the same information, so the model can’t separate their effects, and the standard errors of their coefficients will be inflated. The other pairs of weather variables are only weakly or moderately correlated (all \(|r| \le 0.32\)).

Q7. Models C and E are not nested. Which model do adjusted \(R^2\), AIC, and BIC prefer? Why can’t we use an \(F\) test to compare them?

Model C is preferred by all three: it has the higher adjusted \(R^2\) (0.483 vs. 0.445) and the lower AIC (8459.3 vs. 8493) and BIC (8488.8 vs. 8518.3). We can’t use an \(F\) test because the models are not nested: the \(F\) test compares a model to a special case of itself, but neither C nor E is a special case of the other.

Q8. Do the criteria agree on adding temp_feel to model C (comparing C and D)? What does each one say? Which model would you choose?

They do not agree. Adjusted \(R^2\) barely changes (0.483 for C vs. 0.485 for D) and very slightly favors D. AIC is only 1.3 lower for D (a small difference), while BIC is 2.9 higher for D, so BIC prefers C. The \(F\) test (Q4) was borderline (p = 0.071).

When the tools disagree and there is multicollinearity, choose the simpler model: model C.

Part 4: Interpreting your model

Q9. Which of the five models would you use to answer our question? Justify your choice using what you found above.

Model C (temp_actual + windspeed + weekend + holiday + humidity):

  • It contains our two variables of interest (weekend and holiday), and adjusts for the weather.
  • Adding holiday (A to B) and humidity (B to C) both improved the fit significantly (\(F\) tests).
  • Adding temp_feel (D) doesn’t help much and causes multicollinearity.
  • It beats the non-nested alternative E under every criterion.

(A reasonable alternative answer is B or C, as long as the choice is justified. Models A and E are weaker choices: A leaves out holiday and E has a worse fit.)

Function quick reference

Function Purpose
lm() Fit a linear model
cor() Correlation matrix for a set of quantitative variables
anova(reduced, full) Extra sums of squares \(F\) test comparing two nested models
summary(model)$adj.r.squared Adjusted \(R^2\) for a fitted model
AIC(), BIC() Information criteria for a fitted model (smaller is better)
confint() Confidence intervals for the coefficients of a fitted model

## Overview

Today you will build a model to answer this question: **How are weekends and holidays associated with ridership, after accounting for the weather?** Run the code below to select the columns we will use and fit five candidate models.

```{r}
bikes <- bikes[, c("date", "season", "year", "month", "weekend", "holiday",
                   "temp_actual", "temp_feel", "humidity", "windspeed", "rides")]

bikes_A <- lm(rides ~ temp_actual + windspeed + weekend, data = bikes)
bikes_B <- lm(rides ~ temp_actual + windspeed + weekend + holiday, data = bikes)
bikes_C <- lm(rides ~ temp_actual + windspeed + weekend + holiday + humidity, data = bikes)
bikes_D <- lm(rides ~ temp_actual + windspeed + weekend + holiday + humidity + temp_feel, data = bikes)
bikes_E <- lm(rides ~ temp_feel + humidity + weekend + holiday, data = bikes)
```

## Part 1: Look before you fit

**Q1.** Make a correlation matrix of the weather variables. Which pair of predictors could cause problems if we include both in the same model? What problem?

```{r}
bikes |>
  dplyr::select(temp_actual, temp_feel, windspeed, humidity) |>
  cor()
```

> `temp_actual` and `temp_feel` are almost perfectly correlated ($r =$ `r round(cor(bikes$temp_actual, bikes$temp_feel), 2)`). Including both would cause **multicollinearity**: they carry nearly the same information, so the model can't separate their effects, and the standard errors of their coefficients will be inflated. The other pairs of weather variables are only weakly or moderately correlated (all $|r| \le 0.32$).

## Part 2: Nested models and the $F$ test

**Q2.** Which of these pairs of models are nested? For the pairs that are nested, which is the full model?

- A and B
- B and C
- C and D
- C and E
- A and C

> - A and B: nested; B is full (adds `holiday`)
> - B and C: nested; C is full (adds `humidity`)
> - C and D: nested; D is full (adds `temp_feel`)
> - C and E: **not nested**. E uses `temp_feel` but not `temp_actual` or `windspeed`, so neither model is a special case of the other.
> - A and C: nested; C is full (adds `holiday` and `humidity`, so $d = 2$)

The `anova()` function takes the **reduced** model first and the **full** model second.

**Q3.** Fill in the blanks to run the extra sums of squares $F$ test comparing models A and B, and then models B and C. What do you conclude each time?


```{r}
#| include: false

aCD <- anova(bikes_C, bikes_D)
```

>
> **B vs. C:** $H_0: \beta_{humidity} = 0$. $F =$ `r round(aBC$F[2], 1)` on 1 and `r aBC$Res.Df[2]` df, p-value < 0.001. We reject $H_0$: adding `humidity` removes a large amount of squared error (SSE falls from `r format(round(aBC$RSS[1]), big.mark = ",")` to `r format(round(aBC$RSS[2]), big.mark = ",")`).

**Q4.** Now compare C to D (adding `temp_feel`). What does the $F$ test suggest?

```{r}
anova(bikes_C, bikes_D)
```

> $F =$ `r round(aCD$F[2], 2)` on 1 and `r aCD$Res.Df[2]` df, p-value `r round(aCD$"Pr(>F)"[2], 3)`. At the 5% level, we do **not** reject $H_0$: there is only weak evidence that `temp_feel` helps once `temp_actual` is already in the model. (This is borderline, which is a hint that something odd is going on. See Q5.)

We are 95% confident the true difference is between `r abs(round(ciC["weekendTRUE", 2]))` and `r abs(round(ciC["weekendTRUE", 1]))` fewer rides.
>
> **Holiday:** Holding the other variables constant, holidays have about `r abs(round(cC["holidayyes"]))` fewer rides than non-holidays. We are 95% confident the true difference is between `r abs(round(ciC["holidayyes", 2]))` and `r abs(round(ciC["holidayyes", 1]))` fewer rides.
>
> The holiday interval is much wider because there are only `r sum(bikes$holiday == "yes")` holidays among the `r nrow(bikes)` days in the data, so we have very little information about the holiday effect.

**Q11.** (*Extension*) Let's see what happens when we add some other candidate variables to model C. Compare C to each of the models below. Are these nested comparisons? What do the $F$ test, adjusted $R^2$, AIC, and BIC say? Does adding them change your answer to our question?

```{r}
bikes_F <- lm(rides ~ temp_actual + windspeed + weekend + holiday + humidity + season,
              data = bikes)
bikes_Y <- lm(rides ~ temp_actual + windspeed + weekend + holiday + humidity + year,
              data = bikes)
```

(*Note:* `season` has four levels, so adding it adds three coefficients, i.e., $d = 3$.)

```{r}
anova(bikes_C, bikes_F)
anova(bikes_C, bikes_Y)

tibble::tibble(Model = c("C", "C + season", "C + year"),
               adj_R2 = sapply(list(bikes_C, bikes_F, bikes_Y), function(m) summary(m)$adj.r.squared),
               AIC = sapply(list(bikes_C, bikes_F, bikes_Y), AIC),
               BIC = sapply(list(bikes_C, bikes_F, bikes_Y), BIC)) |>
  knitr::kable(digits = c(0, 3, 1, 1))

confint(bikes_F)[c("weekendTRUE", "holidayyes"), ]
confint(bikes_Y)[c("weekendTRUE", "holidayyes"), ]
```

```{r}
#| include: false
aCF <- anova(bikes_C, bikes_F)
aCY <- anova(bikes_C, bikes_Y)
```

> Both comparisons are nested (C is contained in each larger model). Both additions are strongly supported by every tool:
>
> - **Adding `season`** ($d = 3$): $F =$ `r round(aCF$F[2], 1)`, p < 0.001; adjusted $R^2$ rises from `r round(summary(bikes_C)$adj.r.squared, 3)` to `r round(summary(bikes_F)$adj.r.squared, 3)`; AIC and BIC both drop by more than 55.
> - **Adding `year`** ($d = 1$): $F =$ `r round(aCY$F[2], 1)`, p < 0.001; adjusted $R^2$ jumps to `r round(summary(bikes_Y)$adj.r.squared, 3)`; AIC and BIC both drop by more than 340. Ridership grew a lot from 2011 to 2012, and the index plot of residuals for model C shows this trend over time.
>
> Our conclusions about weekends and holidays do not change much: the estimates are nearly the same (about `r abs(round(coef(bikes_Y)["weekendTRUE"]))` fewer rides on weekends and `r abs(round(coef(bikes_Y)["holidayyes"]))` fewer on holidays with `year` in the model), but the confidence intervals get narrower when we explain more of the variability (the weekend interval with `year` is `r round(confint(bikes_Y)["weekendTRUE", 1])` to `r round(confint(bikes_Y)["weekendTRUE", 2])`). Since the question is about the weekend and holiday effects "after accounting for" other things, a model with `year` (and possibly `season`) is arguably the better final model.

## Function quick reference

| Function | Purpose |
|----|-----------|
| `lm()` | Fit a linear model |
| `cor()` | Correlation matrix for a set of quantitative variables |
| `anova(reduced, full)` | Extra sums of squares $F$ test comparing two nested models |
| `summary(model)$adj.r.squared` | Adjusted $R^2$ for a fitted model |
| `AIC()`, `BIC()` | Information criteria for a fitted model (smaller is better) |
| `confint()` | Confidence intervals for the coefficients of a fitted model |
