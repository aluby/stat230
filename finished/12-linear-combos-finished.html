Calculating CIs for linear combinations

To calculate a confidence interval for a linear combination of coefficients, we must first calculate the estimate and standard error of the linear combination.

The slope for Cadillacs is the sum of the Mileage coefficient (the slope for the baseline, Buick) and the Mileage:MakeCadillac interaction coefficient:

\[\widehat{\beta}_{\text{Mileage}} + \widehat{\beta}_{\text{Mileage:MakeCadillac}}\]

Its standard error uses the variances and the covariance of the two estimates:

\[SE = \sqrt{\widehat{Var}(\widehat{\beta}_{\text{Mileage}}) + \widehat{Var}(\widehat{\beta}_{\text{Mileage:MakeCadillac}}) + 2\,\widehat{Cov}(\widehat{\beta}_{\text{Mileage}}, \widehat{\beta}_{\text{Mileage:MakeCadillac}})}\]

First, extract the coefficients and covariance matrix from the model object.

2car_vcov <- vcov(car_lm2)

t_star <- qt(0.975, df = df.residual(car_lm2))

The critical value is \(t^* =\) 1.963 (on 792 degrees of freedom). The estimated slope for Cadillacs is -6.94e-06 with a standard error of 3.03e-06, so the 95% confidence interval is (-1.29e-05, -9.93e-07).

Interpretation: the response is \(\log(\text{Price})\), so we back-transform. We are 95% confident that, for Cadillacs, every additional 10,000 miles multiplies the expected price by a factor between 0.879 and 0.99, i.e., a decrease of about 1% to 12.1%.

```{r}
car_lm2 <- lm(log(Price) ~ Mileage * Make, data = cars)

```

## Calculating CIs for linear combinations

To calculate a confidence interval for a linear combination of coefficients, we must first calculate the estimate and standard error of the linear combination. 

The slope for Cadillacs is the sum of the `Mileage` coefficient (the slope for the baseline, Buick) and the `Mileage:MakeCadillac` interaction coefficient:

$$\widehat{\beta}_{\text{Mileage}} + \widehat{\beta}_{\text{Mileage:MakeCadillac}}$$

Its standard error uses the variances *and* the covariance of the two estimates:

$$SE = \sqrt{\widehat{Var}(\widehat{\beta}_{\text{Mileage}}) + \widehat{Var}(\widehat{\beta}_{\text{Mileage:MakeCadillac}}) + 2\,\widehat{Cov}(\widehat{\beta}_{\text{Mileage}}, \widehat{\beta}_{\text{Mileage:MakeCadillac}})}$$

First, extract the coefficients and covariance matrix from the model object.

```{r}
car_coefs <- coef(car_lm2) #<1>
car_vcov <- vcov(car_lm2)  #<2>
```

1. Extract the coefficients from the model object and store them in `car_coefs`.
2. Extract the covariance matrix from the model object and store it in `car_vcov`.

Next, calculate the estimate of the slope for Cadillacs.

```{r}
estimate <- car_coefs[2] + car_coefs[8] #<3>
estimate
```

3. `car_coefs` is a vector, so we pull off the necessary coefficients using their position in square brackets. Here, `car_coefs[2]` pulls off the coefficient for `Mileage` and `car_coefs[8]` pulls off the coefficient for the interaction term `Mileage:MakeCadillac`. 

Now, calculate the standard error of the slope for Cadillacs. 

```{r}
se <- sqrt(car_vcov[2,2] + car_vcov[8,8] + 2*car_vcov[2,8]) #<4>
se
```

4. `car_vcov` is a matrix, so we pull off the necessary variances and covariances using their row and column positions in square brackets. Here, `car_vcov[2,2]` pulls off the variance for `Mileage`, `car_vcov[8,8]` pulls off the variance for the interaction term `Mileage:MakeCadillac`, and `car_vcov[2,8]` pulls off the covariance between these two coefficients.

Finally, use the estimate and standard error to calculate a 95% confidence interval for the slope of the Cadillac model. You can use the `qt()` function to find the appropriate critical value.

**Q1.** Calculate a 95% confidence interval for the slope of the Cadillac model.

```{r}
t_star <- qt(0.975, df = df.residual(car_lm2))
t_star

ci <- estimate + c(-1, 1) * t_star * se
ci
```

> The critical value is $t^* =$ `r round(t_star, 3)` (on `r df.residual(car_lm2)` degrees of freedom). The estimated slope for Cadillacs is `r format(estimate, digits = 3)` with a standard error of `r format(se, digits = 3)`, so the 95% confidence interval is (`r format(ci[1], digits = 3)`, `r format(ci[2], digits = 3)`).
>
> **Interpretation:** the response is $\log(\text{Price})$, so we back-transform. We are 95% confident that, for Cadillacs, every additional 10,000 miles multiplies the expected price by a factor between `r round(exp(10000 * ci[1]), 3)` and `r round(exp(10000 * ci[2]), 3)`, i.e., a decrease of about `r round(100 * (1 - exp(10000 * ci[2])), 1)`% to `r round(100 * (1 - exp(10000 * ci[1])), 1)`%.
