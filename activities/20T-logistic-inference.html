Checking conditions

Like in linear regression, we can make plots to assess the fit of our binary logistic regression model. The interpretation of these plots is harder, however, since the response variable is binary; thus, we can’t expect to see a random scatter of points around zero like we did in linear regression. We’ll use two tools:

  1. Empirical logit plots to check the linearity condition (is the log odds a linear function of each predictor?)
  2. Pearson residual plots with a LOESS smoother to check linearity after adjusting for the other predictors, and to look for outliers and patterns over time

Empirical logit plots

To construct an empirical logit plot for a quantitative predictor we follow these steps:

  1. Order the observations by the predictor and use the ordered data to create \(g\) bins of approximately equal size. (A reasonable starting point is \(g = \sqrt{n}\))
  2. In each bin, count the number of successes (\(Y = 1\)) and failures (\(Y = 0\))
  3. Calculate the empirical logit in each bin: \(\log\left(\frac{\#\text{successes} + 0.5}{\#\text{failures} + 0.5}\right)\). (The \(0.5\) keeps us from taking the log of zero in a bin with no successes or no failures.)
  4. Plot the empirical logits against the mean value of the predictor in each bin
  5. Look for a straight-line pattern. A curved pattern suggests that the predictor needs a transformation

Let’s implement these steps for title_words using 13 bins. First, we create the bins and summarize each one:

words_el <- news |>
  mutate(bin = ntile(title_words, 13)) |>
  group_by(bin) |>
  summarize(mean_x = mean(title_words),
            n = n(),
            successes = sum(type_num),
            failures = n - successes,
            emp_logit = log((successes + 0.5) / (failures + 0.5)),
            .groups = "drop")

words_el
NoteAdapting the code

To adapt this code for your own binary logistic regression model, replace news with the name of your data set, title_words with your predictor (in both ntile() and mean()), and type_num with your 0/1 response. You can adjust the number of bins (currently 13) based on your data size.

Next, we plot the empirical logits against the mean predictor value, and add a straight line to help us judge whether the pattern is linear:

gf_point(emp_logit ~ mean_x, data = words_el,
         xlab = "Mean title words in bin", ylab = "Empirical logit") |>
  gf_lm()

Each point is based on only about 11 articles, so expect some scatter around the line. Look for the overall trend, not for individual points.

Categorical predictors

For a categorical predictor, we calculate the empirical logit for each level of the predictor (no bins are needed):

news |>
  group_by(title_has_excl) |>
  summarize(n = n(),
            successes = sum(type_num),
            failures = n - successes,
            emp_logit = log((successes + 0.5) / (failures + 0.5)))

With only two levels, the two points always fall on a straight line, so there is no linearity condition to check for a binary predictor. These plots are more useful for comparing groups (for example, to decide whether an interaction is needed).

Pearson residuals

To create a Pearson residual plot with a LOESS smoother, we can use the resid_panel() command from the {ggResidpanel} package, similar to what we did in linear regression. The only difference is that we need to specify type = "pearson" to indicate that we want to plot Pearson residuals. For binary data the points fall in two curved bands (one for each value of \(Y\)), so the smoother is what we look at. If the model is adequate, it should be roughly a horizontal line at 0.

Below we recreate the residual plots from the slides:

resid_panel(news_mod, plot = "resid", type = "pearson", smoother = TRUE)

resid_xpanel()

To plot the Pearson residuals against each predictor in the model, use resid_xpanel():

#| fig-width: 8
#| fig-height: 3
resid_xpanel(news_mod, yvar = "residual", type = "pearson", smoother = TRUE, nrow = 1)
