Function quick reference

Function Purpose
lm() Fit a linear model
cor() Correlation matrix for a set of quantitative variables
anova(reduced, full) Extra sums of squares \(F\) test comparing two nested models
summary(model)$adj.r.squared Adjusted \(R^2\) for a fitted model
AIC(), BIC() Information criteria for a fitted model (smaller is better)
confint() Confidence intervals for the coefficients of a fitted model

## Function quick reference

| Function | Purpose |
|----|-----------|
| `lm()` | Fit a linear model |
| `cor()` | Correlation matrix for a set of quantitative variables |
| `anova(reduced, full)` | Extra sums of squares $F$ test comparing two nested models |
| `summary(model)$adj.r.squared` | Adjusted $R^2$ for a fitted model |
| `AIC()`, `BIC()` | Information criteria for a fitted model (smaller is better) |
| `confint()` | Confidence intervals for the coefficients of a fitted model |
