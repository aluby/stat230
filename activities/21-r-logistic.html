library(dplyr)

In this activity we’ll compare models for the fake news data using likelihood ratio tests (LRTs) and information criteria. To load the data, run the following code chunk:

# news <- read.csv("https://aluby.github.io/stat230/data/fake_news_bayesrules.csv")
news <- read.csv(here::here("data/fake_news_bayesrules.csv"))

We’ll start from the same model we used last time:

news_mod <- glm(type_num ~ title_words + title_has_excl + title_caps_percent,
                data = news, family = "binomial")

tidy(news_mod)
# A tibble: 4 × 5

3 title_has_exclTRUE   2.00      0.849       2.35 0.0186  
4 title_caps_percent   0.0498    0.0295      1.69 0.0908

Our question today: do we need an interaction between title_has_excl and title_caps_percent? In other words, is the association between the percent of capital letters and the odds of being fake news different for titles with and without an exclamation point?

Part 1: Exploratory data analysis

To check whether the slopes might differ, we make an empirical logit plot with a line for each group. We bin title_caps_percent and calculate the empirical logit within each bin and each group.

news_agg <- news |>
  mutate(tcp_bin = cut(title_caps_percent, c(-Inf, 0, 10, Inf))) |>
  group_by(tcp_bin, title_has_excl) |>
  summarize(mean_x = mean(title_caps_percent),
            n = n(),
            n_fake = sum(type_num),
            emp_logit = log((n_fake + 0.5) / (n - n_fake + 0.5)),
            .groups = "drop")

news_agg

NoteWhy cut() and not ntile()?

About 61% of the titles have exactly 0% capital letters, so equal-size bins would put most bins at the same x value. We create the bins by hand instead.

gf_point(emp_logit ~ mean_x, color = ~title_has_excl, size = ~n, data = news_agg,
         xlab = "Mean title_caps_percent in bin", ylab = "Empirical logit") |>
  gf_line()

Part 3: LRT for the interaction

The likelihood ratio test compares a reduced model to a full model that contains all of the reduced model’s terms (plus some more). In R, we use anova() with test = "LRT", and give the reduced model first.

anova(___, ___, test = "LRT")

Q5. Fill in the blanks to test whether we need the interaction term. Write out the null and alternative hypotheses, then report the test statistic (\(\Lambda\), the Deviance column), the degrees of freedom, the p-value, and your conclusion in context.

Q6. The coefficient table from tidy(news_mod2) also contains a z-test for the interaction term. Compare its p-value to the LRT p-value. Are they close?

We can also verify that the LRT statistic is the drop in deviance. The deviance of a model is \(-2\log L\), and a smaller deviance means a better fit:

deviance(news_mod)   # reduced model
deviance(news_mod2)  # full model
deviance(news_mod) - deviance(news_mod2)

Part 4: Do we need title_has_excl at all?

The variable title_has_excl appears in two terms of the interaction model (the main effect and the interaction), so to ask whether we need it at all we must remove both. Fit this reduced model and use an LRT to compare it to news_mod2:

reduced_model <- glm(type_num ~ title_words + title_caps_percent,
                     data = news, family = "binomial")

anova(reduced_model, news_mod2, test = "LRT")

Q7. Write out the null and alternative hypotheses (in terms of \(\beta\)’s) for this test. How many degrees of freedom does the test have, and why? What do you conclude?

Function quick reference

Function Purpose
glm(y ~ x, data, family = "binomial") Fit a binary logistic regression model
cut(x, breaks) Create bins from specific cut points
anova(reduced, full, test = "LRT") Likelihood ratio test comparing two nested models
deviance(model) Deviance (\(-2 \log L\)) of a fitted model
pchisq(x, df) Probability from a \(\chi^2\) distribution (use 1 - pchisq() for a p-value)
AIC(), BIC() Information criteria for one or more fitted models (smaller is better)

## Function quick reference

| Function | Purpose |
|----|-----------|
| `glm(y ~ x, data, family = "binomial")` | Fit a binary logistic regression model |
| `cut(x, breaks)` | Create bins from specific cut points |
| `anova(reduced, full, test = "LRT")` | Likelihood ratio test comparing two nested models |
| `deviance(model)` | Deviance ($-2 \log L$) of a fitted model |
| `pchisq(x, df)` | Probability from a $\chi^2$ distribution (use `1 - pchisq()` for a p-value) |
| `AIC()`, `BIC()` | Information criteria for one or more fitted models (smaller is better) |
