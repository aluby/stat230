Why doesn’t glm work?

model2 <- glm(Removed ~ distance + morph + distance * morph, 
              data = moths, 
              family = "binomial")

! y values must be 0 <= y <= 1

Binomial response

  • \(Y_i\): the number of moths removed (i.e. “success”) on each tree for each morph

  • We will assume each trial (success/failure) is independent

NoteBinomial distribution

The sum of independent and identically distributed success/failure trials follows a Binomial(n, p) distribution.

  • Theoretical mean: \(E(Y) = np\)
  • Theoretical variance: \(Var(Y) = np(1-p)\)
  • A binary response is the special case where \(n=1\)

Binomial logistic regression

\[\pi_i = P(success | x_1, ..., x_p)\]

Log-odds scale:

\[\text{logit}(\pi_i) = \log (\frac{\pi_i}{1-\pi_i}) = \beta_0 + \beta_1 x_1 + ... + \beta_p x_p = \eta_i\]

Probability scale:

\[\pi_i = \dfrac{e^{\eta_i}}{1 + e^{\eta_i}}= \dfrac{e^{\beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i} + \cdots + \beta_p x_{pi}}}{1 + e^{\beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i} + \cdots + \beta_p x_{pi}}}\]

Fitted model from HW8

\[ \operatorname{\widehat{log\_odds\_removed}} = -1.123 + 0.018(\operatorname{distance}) + 0.374(\operatorname{morph}_{\operatorname{light}}) - 0.028(\operatorname{distance} \times \operatorname{morph}_{\operatorname{light}}) \]

This approach required calculating the empirical log-odds “by hand” and adding to the dataset. Alternatively, we can fit with glm() using the weights argument

model3 <- glm(Removed/Placed ~ distance + morph + distance*morph, 
              weights = Placed,
              data = moths,

Binomial model assumptions

  • Binomial counts: Y is number of successes in \(n\) trials

  • Independence: observations are independent

  • Linearity: the log odds is a linear function of the predictors

  • Variance structure: the variance of a binomial random variable is \(n \pi (1 - \pi)\)

    \(\Longrightarrow\) so the variance of \(Y_i\) is \(n_i \pi_i (1 - \pi_i)\) (not constant!)

Pearson residuals

\[{\rm Pres}_i = \dfrac{Y_i - n_i \widehat{\pi}_i}{\sqrt{n_i \widehat{\pi}_i (1 - \widehat{\pi}_i)}}\]

For large enough \(n_i\), Pearson residuals tend to behave like they come from \(N(0,1)\)

How to use?

  • Plot against fitted values, predictors

  • Check for curvature, outliers

Pearson residuals

Pearson \(\chi^2\)

Pearson’s \(\chi^2\) statistic can be used to assess the overall fit of a binomial logistic regression model

Observed Count Predicted P(Success) True P(Success) Predicted Count
\(Y_i\) \(\widehat{\pi}_i\) \(\pi_i\) \(m_i \widehat\pi_i\)

Pearson \(\chi^2\): \(X^2 = \sum \dfrac{(Y_i - m_i\widehat{\pi}_i)^2}{m_i\widehat{\pi}_i (1 - \widehat{\pi}_i)} = \sum {\rm Pres}_i^2\)

\(X^2\) is small when the predicted counts are close to the observed counts (good), and large when they are far away (bad)


\(X^2 \overset{\cdot}{\sim} \chi^2\) with \(\text{d.f.}= n-(p+1)\), if the model is correct and all \(m_i\) are large enough (>5)

\(n =\) # of binomial observations (# of proportions, not # of moths)

Goodness-of-fit test

(the model is adequate)

H0: \({\rm logit}(\pi_i) = \beta_0 + \beta_1 x_{1i} + \cdots + \beta_p x_{pi}\)

(the model is inadequate)

Ha: \({\rm logit}(\pi_i) = \alpha_i\)
