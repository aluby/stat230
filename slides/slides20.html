Fitted regression model: 3 scales

\(\log(\frac{\widehat p}{1-\widehat p}) = \widehat\beta_0 + \widehat\beta_1 x\)

\(\text{odds}(x) = e^{\widehat\beta_0 + \widehat\beta_1 x}\)

\(P(Y = 1 | x) = \frac{e^{\widehat\beta_0 + \widehat\beta_1 x}}{1 + e^{\widehat\beta_0 + \widehat\beta_1 x}}\)

Logistic regression: linear predictor with a logit link function

\(\widehat \eta = \log(\frac{\widehat p}{1-\widehat p}) = \widehat\beta_0 + \widehat\beta_1 x\)

Link function: logit

\(\widehat \eta \to P(Y=1)\)

\(P(Y = 1 | x) = \frac{e^{\widehat\beta_0 + \widehat\beta_1 x}}{1 + e^{\widehat\beta_0 + \widehat\beta_1 x}}\)

Linear regression: linear predictor with an identity link function

\(\widehat \eta = \widehat y = \widehat\beta_0 + \widehat\beta_1 x\)

Link function: identity

\(f(\eta) = \eta\)

\(\widehat y= \widehat \beta_0 + \widehat \beta_1 x\)

Generalized linear model


Linear Predictor

\(\eta = \beta_0 + \beta_1 x_1 + ... + \beta_p x_p\)


Link Function

\(\theta = g(\eta)\)


Response distribution

\(Y\) is a random variable with mean \(\theta\)

Binary logistic regression

If \(Y\) follows a Bernoulli distribution

\[{\rm E}(Y | X) = \pi(X)\]

We link this mean function to the explanatory variables using the logit link

\[\begin{align*} \eta &= {\rm logit}(\pi(X))\\ &= \log \left( \dfrac{\pi(X)}{1 - \pi(X)} \right) = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_p x_p \end{align*}\]

Wald-based inference

Maximum likelihood (ML) estimation

The coefficients in logistic regression are estimated by finding the \(\widehat{\beta}_0, \ldots, \widehat{\beta}_p\) that maximize the probability of the observed outcomes

\[L(\beta) = P(Y_1 = y_1, \ldots Y_n = y_n | \beta, X) = \prod_{i=1}^{n} \pi(X)^{y_i} \Big[ 1 - \pi(X) \Big]^{1- y_i}\]

where

\[\pi(X) = \dfrac{e^{\beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p}}{1 + e^{\beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p}}\]

For more, consider taking Stat250!

Properties of ML estimators

If the sample is large and the model is correct, the ML estimator \(\hat\beta_i\) is:

  1. Essentially unbiased

  2. SEs can be computed and are about as small as any other unbiased estimator

  3. The sampling distributions for the estimators are approximately normal

For more, consider taking Stat250!

Wald test for a coefficient

Hypotheses:

\(H_0: \beta_i = 0 \quad\) vs. \(\quad H_a: \beta_i \ne 0\)

Test statistic:

\(z = \dfrac{\widehat{\beta}_i}{SE(\widehat{\beta}_i)}\)


Reference distribution:

\(N(0, 1)\)

CI for a coefficient

A normal-based confidence interval for \({\beta}_i\)

\[\widehat{\beta}_i \pm z^*_{1-\alpha/2} SE(\widehat{\beta}_i)\]

CI for the multiplicative effect on odds of success for a 1- unit change in \(x\) (odds ratio of Success for \(x+1\) vs. \(x\)):

\[e^{\widehat{\beta}_i - z^*_{1-\alpha/2} SE(\widehat{\beta}_i)} \quad \text{to} \quad e^{\widehat{\beta}_i + z^*_{1-\alpha/2} SE(\widehat{\beta}_i)}\]

… for a \(C\)-unit change in \(x\)

\[e^{C \cdot\widehat{\beta}_i - z^*_{1-\alpha/2} C \cdot SE(\widehat{\beta}_i)} \quad \text{to} \quad e^{C \cdot\widehat{\beta}_i + z^*_{1-\alpha/2} C \cdot SE(\widehat{\beta}_i)}\]

How can we tell if inference is correct?

Recall

LINE conditions must be met for inference to be valid

  • If Linearity fails, the line doesn’t actually describe the relationship and everything breaks

  • If INE fails, we can still interpret our coefficients (the geometry is still correct), but cannot trust inference

    • Confidence intervals too narrow
    • p-values too small

What are the conditions for logistic regression model?

  1. Linear relationship between the log odds (logit) and the predictors

  2. Independence: no pairs, clusters, etc.

  3. Randomness: we have a random sample from the population or the data were collected from a randomized experiment

“Residuals”

In logistic regression, we’ll work with residuals on the response scale:

\[e_i = y_i - \widehat \pi_i = \begin{cases} 1 - \widehat \pi_i & \text{if } y_i = 1 \\ - \widehat \pi_i & \text{if } y_i = 0 \end{cases}\]

What will residual plot look like?

Residual plot

resid_panel(news_mod, plot = "resid", type = "response")

Binned residuals

Idea: If we group data points based on predictor, we can compute the mean response residual within each group and end up with something that looks more like an OLS residual plot

  1. Calculate response residual
  2. Order observations either by the values of the predicted log odds/probabilities, or by quantitative predictor variable
  3. Use the ordered data to create g bins of approximately equal size. (Default: \(g = \sqrt{n}\))
  4. Calculate average residual value in each bin
  5. Plot average residuals vs. average predicted log odds, probability, or predictor value

Pearson residual

Standardize the distance between the observation (0 or 1) and the expected value (probability)

\[r_{p_i} = \frac{y_i - \widehat \pi_i}{\sqrt{\widehat{\pi_i}(1-\widehat \pi_i)}}\]

Pearson residuals in R

  • If the model is correct, then the expected (average) Pearson residual within each bin should be close to 0
  • A smoother should be approximately horizontal line at 0
resid_panel(news_mod, plot = "resid", type = "pearson")
resid_panel(news_mod, plot = "resid", type = "pearson", smoother = TRUE)

Smoothers can help draw attention to major flaws, but there will always be variation from the horizontal!

Independence

  • We conduct inference assuming we have \(n\) pieces of independent information from the \(n\) data points
  • If the data points are dependent, we have less pieces of information than \(n\) and our inference is overoptimistic
  • Best to assess based on description of the data:
    • Are they grouped in some way?
    • Measurements over time?
    • Spatial component?
  • The reason we make an index plot is to see if our data is ordered in some way
