Parallel lines model

FEV increases at the same rate with age, but is shifted up or down for smokers

Different slopes model

FEV starts at the same baseline (age 0), but the relationship between age and FEV is different for smokers vs nonsmokers

Separate lines model

Smokers/nonsmokers have different baselines and different relationships between age and FEV

Parallel lines model

\[\mu(y|x) = \beta_0 + \beta_1 \texttt{age} + \beta_2 \texttt{smoker}\]


  • \(\beta_0\): intercept for nonsmokers
  • \(\beta_0 + \beta_2\): intercept for smokers
  • \(\beta_1\): slope for both groups

Different slopes model

\[\mu(y|x) = \beta_0 + \beta_1 \texttt{age} + \beta_2 \texttt{age} \times \texttt{smoker}\]


  • \(\beta_0\): intercept for both groups
  • \(\beta_1\): slope for nonsmokers
  • \(\beta_1 + \beta_2\): slope for smokers

Separate lines model

\[\mu(y|x) = \beta_0 + \beta_1 \texttt{age} + \beta_2 \texttt{smoker} + \beta_3 \texttt{age} \times \texttt{smoker}\]


  • \(\beta_0\): intercept for nonsmokers
  • \(\beta_0 + \beta_2\): intercept for smokers
  • \(\beta_1\): slope for nonsmokers
  • \(\beta_1 + \beta_3\): slope for smokers

Fitting the separate lines model in R

fev_sep <- lm(FEV ~ Age * Smoke, data = fev)
coef(fev_sep)
    (Intercept)             Age     SmokeSmoker Age:SmokeSmoker 
      0.6747724       0.2097247       1.7197133      -0.1432927


R names an indicator after the level that is coded 1. The level that never appears in a coefficient name (here, Nonsmoker) is the reference level.

Reading the coefficient names

R output Model term Meaning
(Intercept) \(\beta_0\) intercept for nonsmokers (reference level)
Age \(\beta_1\) slope for nonsmokers
SmokeSmoker \(\beta_2\) difference in intercepts (smokers \(-\) nonsmokers)
Age:SmokeSmoker \(\beta_3\) difference in slopes (smokers \(-\) nonsmokers)

Fitted lines:

Nonsmokers: \(\widehat{\text{FEV}} = 0.67 + 0.21 \, \texttt{age}\)


Smokers: \(\widehat{\text{FEV}} = (0.67 + 1.72) + (0.21 -0.14) \, \texttt{age} = 2.39 + 0.07 \, \texttt{age}\)
