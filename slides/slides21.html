Likelihood Ratio Test

Hypotheses:

\(H_0: \beta_i = \beta_j = ... = 0 \quad\) vs. \(\quad H_a: \text{at least 1 } \beta \ne 0\)

Test statistic:

\[\Lambda = 2 \log \frac{\text{max likelihood in full model}}{\text{max likelihood in reduced model}}\]


Reference distribution:

\(\chi^2_{df}\) where \(df=\) number of extra terms in the full model

Idea: how much did the full model increase the likelihood over the small model? (High likelihood = good, low likelihood = less good)

Z-test vs LRT

Test for one coefficient \(H_0: \beta_i = 0\) against \(H_A: \beta_i \ne 0\):

  • In OLS, the t-test and F-test give exactly the same p-values if you are comparing 1 coefficient
  • In logistic regression, the z-test and LRT are not equivalent
    • Hopefully they are close
    • If not, the LRT is usually more accurate

AIC and BIC for logistic regression

The following “information criteria” can be used to compare nested or non-nested models (smaller values are better)

\[IC = \text{Measure of Fit} + \text{Penalty}\]


\[AIC = n \log(L) + 2p\]


\[BIC = n \log(L) + \log(n) \cdot p\]

where L is the likelihood of the model
