Review: SST/SSReg/SSE

But, we work with sum of squares

Linear Regression tilt and shifts the line until the total area of the red squares are as small as possible (“least squares”)

\(R^2\): proportion of the blue area (SSTotal) that is successfully covered by the green squares (SSRegr)

\(R^2_{adj} = 1 - \frac{MSE}{MST}\): same idea, but each model is “charged” for the number of \(\beta\)’s it uses

\(h_i\): a point becomes more influential as it moves further away from \(\bar{x}\) because the corresponding red square grows quadratically

Overall F test: \(F = \frac{MSReg}{MSE}\)

  • is the “average” green square significantly larger than the “average” red square?

Sequential sum-of-squares F test: \(F=\frac{(SSE(reduced)-SSE(full))/(df_{reduced}-df_{full})}{SSE(full)/df_{full}}\)

  • are the red squares for a “larger” model significantly smaller than the red squares for a “smaller” model?

A recipe for explanatory models

  1. Start with the question. Which variables are you interested in? Which do you need to adjust for? These stay in the model, even if they aren’t “significant”
  2. Look before you fit. Check for predictors that carry (almost) the same information
  3. Fit a small set of candidate models (not every possible combination!)
  4. Compare the candidates: \(F\) test for nested models; adjusted \(R^2\), AIC, or BIC for any models
  5. Check the conditions for the model you choose
  6. Interpret and justify your choice

. . .

\[F = \frac{(SSE_{reduced} - SSE_{full}) / d}{SSE_{full} / df_{full}}\]

  • Numerator: improvement per \(\beta\) added
  • Denominator: average variance/noise in the full model
  • A large \(F\) means: the bigger model reduces SSE by much more than we’d expect from noise alone.

When the \(F\) test can’t help

bikes_C <- lm(rides ~ temp_actual + windspeed + weekend + holiday + humidity, data = bikes)
bikes_E <- lm(rides ~ temp_feel + humidity + weekend + holiday, data = bikes)

Is bikes_E nested in bikes_C? Could we use anova(bikes_E, bikes_C)?

. . .

  • Non-nested models: neither is a special case of the other, so the \(F\) test does not apply
  • Many candidate models: each \(F\) test needs a nested pair, and repeated testing is a problem
  • We need tools that work for any two models fit to the same data

Adjusted \(R^2\)

\(R^2_{adj} = 1 - \dfrac{MSE}{MST} = 1 - \dfrac{SSE/(n-(p+1))}{SST/(n-1)}\)

  • \(R^2\) always goes up when we add predictors; \(R^2_{adj}\) can go down
  • can be used for nested and non-nested models
  • no formal test/rules for “better enough”
summary(bikes_C)$adj.r.squared
[1] 0.4825335
summary(bikes_E)$adj.r.squared
[1] 0.4453567

Information criteria: AIC and BIC

The following “information criteria” can be used to compare nested or non-nested models (smaller values are better)

\[IC = \text{Measure of Fit} + \text{Penalty}\]


\[AIC = n \log(SSE/n) + 2(p+1)\]

\[BIC = n \log(SSE/n) + \log(n) \cdot (p+1)\]

\(p\) = number of predictors in the model. Fit term gets smaller with a bigger model; the penalty gets bigger. BIC penalizes more than AIC (since \(\log(n) > 2\) when \(n \ge 8\))

In R: AIC(model) and BIC(model)

Example: adjusted \(R^2\) and \(F\) tests by hand

A researcher fits four nested models to \(n = 40\) observations. Fill in the table, then answer the questions.
