Review: sums of squares

  • Least squares makes the total area of the ______________ squares as small as possible
  • \(R^2\): proportion of the ______________ area (SST) covered by the ______________ squares (SSReg)
  • \(R^2_{adj} = 1 - \frac{MSE}{MST}\): same idea, but each model is “charged” for the number of ______________ it uses
  • Overall \(F\) test, \(F = \frac{MSReg}{MSE}\): is the “average” ______________ square bigger than the “average” ______________ square?
  • Extra sums of squares \(F\) test: are the ______________ squares for a larger model significantly smaller than for a smaller model?

Two situations where the \(F\) test can’t help:

We need tools that work for any two models fit to the same data.

Adjusted \(R^2\)

\[R^2_{adj} = 1 - \frac{MSE}{MST} = 1 - \frac{SSE/(n-(p+1))}{SST/(n-1)}\]

  • \(R^2\) always goes up when we add predictors; \(R^2_{adj}\) ______________
  • can be used for nested and non-nested models
  • no formal test or rule for “better enough”

E: temp_feel + humidity + weekend + holiday 0.445

Information criteria: AIC and BIC

\[IC = \text{Measure of Fit} + \text{Penalty}\]

\[AIC = n \log(SSE/n) + 2(p+1) \qquad\qquad BIC = n \log(SSE/n) + \log(n) \cdot (p+1)\]

where \(p\) = number of predictors. In R:

AIC(model) and BIC(model).

  • Smaller values are ______________.
  • When we add a predictor, the fit term gets ______________ and the penalty gets ______________.
  • BIC penalizes more than AIC whenever \(\log(n) >\) ______, i.e. \(n \ge\) ______.

Example: adjusted \(R^2\) and \(F\) tests by hand

A researcher fits four nested models to \(n = 40\) observations. Fill in the table, then answer the questions.

Model Predictors \(p\) SSE \(\hat\sigma^2 = SSE/(n-(p+1))\) \(R^2_{adj}\)
M0 none 0 980 25.13 0
M1 \(x_1\) 1 520 13.68 0.455
M2 \(x_1, x_2\) 2 410
M3 \(x_1, x_2, x_3\) 3 398

\(R^2_{adj} = 1 - \hat\sigma^2 / \hat\sigma^2_{M0}\) (since \(MST = SSE_{M0}/(n-1)\)).

(a) Which model is best by \(R^2_{adj}\)?

(b) Use an \(F\) test to compare M3 to M2. State \(d\) and \(df_{full}\). (reminder: \(F = \frac{(SSE_{reduced} - SSE_{full}) / d}{SSE_{full} / df_{full}}\))

(c) Do the two tools agree? Which model would you choose?
